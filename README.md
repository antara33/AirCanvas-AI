# AirCanvas AI

A real-time hand gesture-based drawing application built using Python, OpenCV, and MediaPipe.

## Features

- Real-time hand tracking
- Gesture-based cursor control
- Air drawing
- Multiple drawing colors
- Brush size adjustment
- Basic shape drawing
- Smart shape recognition
- Eraser
- Undo and Redo
- Save drawings
- Drawing gallery

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python main.py

## About

AirCanvas AI is my first Computer Vision project, developed to explore hand tracking, gesture recognition, and interactive drawing without using a traditional mouse.
